User Roles & Approval System

The current project allows everyone to register as a normal user only.

I want to implement a complete Role-Based Access Control (RBAC) system.

Required user roles:

* Patient (Default User)
* Doctor
* Pharmacy
* Laboratory
* Radiology Center
* Hospital / Medical Center
* System Administrator

⸻

Registration

Patients register directly.

Doctors, pharmacies, laboratories, radiology centers, and hospitals must have separate registration forms with their required information and supporting documents.

Examples:

Doctor:

* Full Name
* National ID
* Medical License Number
* Syndicate Registration Number
* Specialty
* Governorate
* Clinic Address
* Phone
* Email
* Upload National ID
* Upload Medical License

Pharmacy:

* Pharmacy Name
* License Number
* Pharmacist Name
* Address
* Phone
* Upload License

Laboratory:

* Laboratory Name
* License
* Address
* Manager
* Phone

Radiology Center:

* Center Name
* License
* Address
* Manager

Hospital:

* Hospital Name
* Address
* License
* Manager

⸻

Approval Workflow

After registration, these accounts must remain Pending.

They cannot access professional features until approved.

The administrator must review the submitted documents and approve or reject the request.

The applicant should see:

Your registration request has been received and is under review by the medical administration.

⸻

Administrator Dashboard

Create an approval dashboard where the administrator can:

* View pending requests.
* Review uploaded documents.
* Approve or reject applications.
* Add notes.
* Suspend accounts.
* Activate accounts.

⸻

Dashboards

After login:

Patient → Patient Dashboard

Doctor → Doctor Dashboard

Pharmacy → Pharmacy Dashboard

Laboratory → Laboratory Dashboard

Radiology Center → Radiology Dashboard

Hospital → Hospital Dashboard

Administrator → Admin Dashboard

Each dashboard must contain only the tools related to that role.

⸻

Permissions

Implement proper permission control.

Users must never access dashboards that do not belong to their role.

⸻

Testing

Test every role separately.

Verify permissions, login, approval workflow, and dashboard access.
