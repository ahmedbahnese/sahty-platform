Healthcare UI/UX Design Philosophy

Use the following design philosophy for this project.
<frontend_aesthetics>
Before writing any code, define the design vision by answering:
1. What healthcare problem does this interface solve?
2. Who is the primary user of this screen?
3. What is the emotional feeling the interface should create? (Trust, Calmness, Speed, Professionalism, Safety)
4. What is the one visual element users will always remember about “Sahti”?
⸻

Design Philosophy
Design the interface as a premium healthcare platform comparable to enterprise medical systems.
The design should communicate:
* Trust
* Professionalism
* Simplicity
* Speed
* Accessibility
* Safety
Every screen should immediately feel like a real medical platform rather than a generic dashboard.
⸻
Visual Style
Choose a clean modern medical aesthetic.
Inspired by:
* Apple Health
* Epic Systems
* Cerner
* Google Health
* Microsoft Fluent
* Modern Hospital Information Systems
Avoid generic admin dashboard templates.
⸻
Typography
Choose elegant professional typography.
Use:
* One display font
* One readable body font
Typography must prioritize readability for healthcare professionals.
Avoid:
* Inter
* Arial
* Roboto
* Generic system fonts
⸻
Color System
Create a complete healthcare color system using CSS Variables.
Use:
Primary Medical Color
Secondary Accent
Emergency Color
Warning Color
Success Color
Information Color
Neutral Palette
Dark Theme Palette
Light Theme Palette

Colors must clearly communicate medical status.

⸻
Layout
Design using modern spacing principles.
Requirements:
Consistent spacing
Visual hierarchy
Large clickable areas
Clear information grouping
Responsive layouts
Do not overcrowd interfaces.
Medical information must always be easy to scan.
⸻
Motion
Animations should improve usability.
Use:
Smooth page transitions
Loading skeletons
Progress indicators 
Subtle hover effects
Animated notifications
Animated charts
Avoid distracting animations.

Dashboard Design
Every user role must have its own visual identity while remaining part of the same design system.
Create dedicated dashboards for:
* Patient
* Doctor
* Hospital
* Laboratory
* Radiology Center
* Pharmacy
* Administrator
Each dashboard should display only the most relevant information for that role.

Follow Material Design 3 and modern Healthcare UX best practices where they improve usability, but create a unique visual identity for Sahti instead of copying existing products. Every screen should prioritize speed, clarity, accessibility, and patient safety while maintaining a premium appearance.

Create a premium animation system for the entire Sahti platform.

The animations should feel smooth, modern, and professional.

Use animations to improve user experience, not just decoration.

Implement:

• Smooth page transitions.
• Fade and slide entrance animations.
• Staggered loading animations.
• Skeleton loading while fetching data.
• Animated dashboard cards.
• Smooth sidebar expansion.
• Animated charts.
• Floating AI Assistant animation.
• Medical notifications with subtle motion.
• Success, warning, and error animations.
• Interactive buttons with ripple and hover effects.
• Smooth modal and dialog transitions.
• Expandable medical timeline animations.
• Appointment booking progress animation.
• Drag-and-drop upload animations.
• File upload progress indicators.
• Search result animations.
• Micro-interactions throughout the platform.
Use 60 FPS animations.
Animations must never slow down the application.
Respect users who prefer reduced motion.
Use CSS animations where possible and Motion library for React when needed.
