# Sahty Mobile

The isolated Flutter foundation for the Sahty healthcare platform. It consumes
the existing Flask API; it does not replace the React/Vite web app or backend.

See the repository-level [MOBILE.md](../MOBILE.md) for toolchain, API configuration,
and build commands. See [MOBILE_RELEASE_STATUS.md](../MOBILE_RELEASE_STATUS.md)
for verified release status and remaining blockers. [MOBILE_SETUP.md](../MOBILE_SETUP.md)
contains the existing authentication and environment reference.
