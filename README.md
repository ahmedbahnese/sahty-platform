# تطبيق صحتي - سطح المكتب

هذا المجلد يحتوي على الكود المصدري لتطبيق "صحتك في أمان" لأنظمة سطح المكتب (Windows، macOS، Linux).

## الميزات الرئيسية:
- واجهة مستخدم متجاوبة تعمل على جميع أنظمة التشغيل.
- تكامل مع الواجهة الخلفية (API) لجلب وعرض البيانات.
- دعم الإشعارات والتنبيهات.
- إمكانية العمل بدون اتصال بالإنترنت.
- واجهة مخصصة للأطباء والمدراء.

## التقنيات المستخدمة:
- Electron.js لتطوير التطبيق متعدد المنصات.
- React.js للواجهة الأمامية.
- Node.js للعمليات الخلفية.

## متطلبات التشغيل:
- Node.js 16+
- npm أو yarn
- نظام التشغيل: Windows 10+، macOS 10.15+، أو Linux

## كيفية التشغيل:
1. قم بتثبيت التبعيات: `npm install`
2. لتشغيل التطبيق في وضع التطوير: `npm run dev`
3. لبناء التطبيق للإنتاج: `npm run build`
4. لإنشاء ملفات التثبيت: `npm run dist`

## البنية الأساسية:
- `src/`: الكود المصدري للتطبيق.
- `src/renderer/`: ملفات واجهة المستخدم (React).
- `src/main/`: العمليات الرئيسية (Electron Main Process).
- `assets/`: ملفات الموارد (الصور، الأيقونات).
- `build/`: ملفات البناء والتوزيع.

## التوثيق:
سيتم توفير توثيق مفصل لكل مكون ووظيفة داخل الكود.
