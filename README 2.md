# تطبيق صحتي - Android

هذا المجلد يحتوي على الكود المصدري لتطبيق "صحتك في أمان" على نظام Android.

## الميزات الرئيسية:
- واجهة مستخدم متجاوبة مع مبادئ Material Design.
- تكامل مع الواجهة الخلفية (API) لجلب وعرض البيانات.
- دعم الإشعارات والتنبيهات.
- الوصول إلى ميزات الجهاز مثل الكاميرا والموقع.

## متطلبات التشغيل:
- Android Studio
- Android SDK (API 21+)
- Java Development Kit (JDK) 11+

## كيفية التشغيل:
1. افتح المشروع في Android Studio.
2. قم بتثبيت التبعيات اللازمة.
3. قم بتوصيل جهاز Android أو استخدم محاكي.
4. انقر على زر \"Run\" لتشغيل التطبيق.

## البنية الأساسية:
- `app/src/main/java/com/sahty/android/`: الكود المصدري للتطبيق.
- `app/src/main/res/`: ملفات الموارد (التخطيطات، الصور، القيم).
- `build.gradle`: ملفات إعداد البناء.

## التوثيق:
سيتم توفير توثيق مفصل لكل مكون ووظيفة داخل الكود.
