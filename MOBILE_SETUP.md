# Sahty Mobile Setup

The mobile application is isolated under `/mobile` and does not replace the
React/Vite web application or the Flask backend.

## Toolchain

- Flutter 3.32.0
- Dart 3.8.0
- Android/iOS project files generated by `flutter create`
- Android SDK and Xcode are not installed in the current Linux Replit
  environment, so device/platform builds remain to be verified on the
  corresponding toolchains.

## Install and run

```bash
cd mobile
flutter pub get
flutter run
```

The foundation currently opens a real login screen and uses the existing Flask
authentication API. It intentionally does not show fake dashboards or medical
data.

## API configuration

The client reads `API_BASE_URL` at compile time:

```bash
flutter run --dart-define=API_BASE_URL=https://your-api.example.com/api
```

Defaults:

- Android emulator: `http://10.0.2.2:5001/api`
- iOS simulator: use `http://127.0.0.1:5001/api` when the Flask server is
  running on the host, supplied with `--dart-define`
- Physical devices: use an HTTPS URL reachable from the device

The backend requires `SESSION_SECRET` to start. Never put that secret, JWT
signing material, or a production token in the Flutter source or logs.

## Authentication foundation

- Login: `POST /api/auth/login`
- Profile/session restoration: `GET /api/auth/profile`
- Logout: `POST /api/auth/logout`
- Role switching: `POST /api/auth/switch-role`
- Bearer token: `Authorization: Bearer <token>`
- Token and the minimal user summary: platform secure storage via
  `flutter_secure_storage`
- Unauthorized responses: clear the local session and return the user to login
- Timeouts, network failures, non-JSON errors, and API messages are converted
  to safe `AppException` values

The mobile client does not store passwords and does not log tokens or medical
data.

## Android

Open `/mobile/android` in Android Studio with the Android SDK installed, or
run:

```bash
cd mobile
flutter build apk --dart-define=API_BASE_URL=https://your-api.example.com/api
```

This Replit environment has a valid generated Android project but no Android
SDK, so `flutter doctor` reports Android as unavailable here.

## iOS

On macOS with Xcode installed:

```bash
cd mobile
flutter build ios --release --dart-define=API_BASE_URL=https://your-api.example.com/api
```

iOS configuration is generated and checked into `/mobile/ios`. iOS compilation
requires macOS/Xcode and was not executable in the current environment.
