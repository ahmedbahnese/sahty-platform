# تطبيق صحتي - iOS

هذا المجلد يحتوي على الكود المصدري لتطبيق "صحتك في أمان" على نظام iOS.

## الميزات الرئيسية:
- واجهة مستخدم متجاوبة مع مبادئ Human Interface Guidelines.
- تكامل مع الواجهة الخلفية (API) لجلب وعرض البيانات.
- دعم الإشعارات والتنبيهات.
- الوصول إلى ميزات الجهاز مثل الكاميرا والموقع.
- دعم Face ID و Touch ID للمصادقة.

## متطلبات التشغيل:
- Xcode 14+
- iOS 13.0+
- macOS 12.0+
- Swift 5.7+

## كيفية التشغيل:
1. افتح ملف `.xcodeproj` أو `.xcworkspace` في Xcode.
2. قم بتثبيت التبعيات اللازمة باستخدام CocoaPods أو Swift Package Manager.
3. اختر جهاز iOS أو محاكي.
4. انقر على زر \"Run\" لتشغيل التطبيق.

## البنية الأساسية:
- `SahtyApp/`: الكود المصدري للتطبيق.
- `SahtyApp/Views/`: ملفات واجهة المستخدم.
- `SahtyApp/Models/`: نماذج البيانات.
- `SahtyApp/Services/`: خدمات التكامل مع API.
- `SahtyApp/Resources/`: ملفات الموارد (الصور، الألوان، الخطوط).

## التوثيق:
سيتم توفير توثيق مفصل لكل مكون ووظيفة داخل الكود.
